# Integrity review 1 — findings

Verdict: FIX-FIRST

## Findings

1. [BLOCKER] The live adapter removes the mutation evidence and does not tell the agent how to use tools — `src/skill_lab/config.py:232` — `_request_body()` routes every request without a prebuilt `messages` list through `_messages_from_agent_request()`, but that function serializes only `task`, `task_id`, and `tool_history` (`config.py:282-299`). A direct probe produced mutation content `{"task": null, "task_id": null, "tool_history": []}` despite inputs containing `current_skill: ...SECRET-SKILL` and `train_failures: ...SECRET-FAILURE`; the agent probe produced only `Handle incident`, omitting `available_tools` and the required JSON action protocol. Thus a live mutation never sees the current skill or failures, and a live agent receives neither tool schemas nor action instructions, so the paid run would not execute the contracted experiment. — Add distinct, tested live serialization for agent and mutation envelopes; include the current skill, complete train-failure packets, tool schemas, and exact action/response contract.

2. [BLOCKER] The publishable ablation artifact discards mutation prompts, all train/validation trajectories, and rejected/intermediate skill bodies — `src/skill_lab/reporting.py:91` — `write_artifact()` can only serialize optional records that are not fields of `ExperimentResult` (`experiment.py:129-142`); `_prompts_jsonl()` therefore emits an empty stream (`reporting.py:253-259`), `_run_records()` finds only `held_out_runs`, and `_write_skill()` copies only the final skill (`reporting.py:262-269`). The CLI runs evolution in a temporary skills root that is deleted before writing (`cli.py:333-357`). Reproduction over the committed example found, in each branch, `generations=2`, `prompts=0`, and exactly 18 result/trajectory rows whose only split is `test`; the verified artifact has no rejected `v003`, and the naive artifact has no intermediate `v002`. This violates exact prompt capture, complete trajectory retention, and preservation of rejected mutations, making promotion decisions and negative generations unauditable after publication. — Carry every run, exact mutation request/response, and every candidate skill into the result/export path (or export the branch stores), and assert expected train+validation+test counts and all lineage versions before deleting temporary state.

3. [MAJOR] Live rerun validates output files but not the external scientific inputs before spending — `src/skill_lab/cli.py:243` — after checking the artifact manifest, `rerun` loads dataset and fixture paths from `config.json`, performs the complete ablation, and only then byte-compares trees (`cli.py:243-257`). `_verify_manifest()` hashes only files already below the artifact root (`cli.py:440-480`); the example manifest contains neither dataset nor fixture copies/hashes, while its config points to `datasets/incident_tasks.json` and `datasets/tool_world.json`. A changed external corpus therefore triggers live calls before the eventual mismatch, contrary to the hash-abort contract, and the original input bytes cannot be reconstructed from the artifact. — Freeze dataset/fixtures (and other prompt inputs) in the artifact with hashes, verify all hashes before model creation or calls, and rerun from those frozen copies.

4. [MAJOR] Actual live model identity and latency are discarded — `src/skill_lab/experiment.py:1532` — response `model` is captured transiently in `_Usage` but is used only for price lookup and is absent from `RunRecord`, summaries, CSV, trajectories, and the report; the artifact records only the requested config model. Separately, `OpenAICompatibleClient.complete()` hardcodes every response latency to zero (`config.py:211-218`). Provider routing to a different model would be invisible, and all published live latency comparisons would falsely report zero. — Persist the response model ID per call/run and surface it in comparisons/reports; measure elapsed request latency with a monotonic clock (kept as observed metadata, not a deterministic comparison input) or ingest authoritative provider latency.

5. [MAJOR] Non-finite costs can pass the promotion gate instead of becoming inconclusive — `src/skill_lab/promotion.py:112` — `_inconclusive()` checks split, counts, regression denominator, and error outcomes but never finiteness. `EvaluationSummary.estimated_cost_usd` permits infinity (`metrics.py:83-87`). A direct probe with parent cost `float("inf")`, candidate cost `1.0`, strict validation lift, and otherwise valid summaries returned `decision='promote'`; its JSON-mode evidence converted the infinite parent cost and cost limit to `null`. PLAN §8 explicitly defines any nonfinite metric as inconclusive. — Reject non-finite numeric fields at model construction and defensively check `math.isfinite` for every promotion metric before arithmetic.

6. [MAJOR] The held-out report duplicates every result row — `src/skill_lab/reporting.py:301` — `_report()` reads both `held_out_summaries` and its alias `heldout_summaries`; both return the same list (`experiment.py:162-166`), and `_summary_records()` concatenates without deduplication. The committed verified report consequently repeats all three held-out rows at `artifacts/example-mock/report.md:30-35` (six rows with pairwise identical values); the naive report does the same. This is a generator bug in the headline table and can double-count results copied from the report. The conclusion also always says held-out interpretation is unavailable even when those rows exist (`reporting.py:398`). — Read the canonical field once (or deduplicate by condition/split/skill), condition the conclusion on actual held-out presence, and test exact row count/content.

7. [MAJOR] The claimed poison boundary test does not prove the frozen leakage contract — `tests/test_held_out.py:22` — the test poisons only `Task.input`, not expected outcomes, trajectories, store rows, mutation responses, or candidate Markdown, and asserts only serialized model requests (`test_held_out.py:94-110`). There is no poisoned store in this path. Moreover, `evolve()` is handed the full corpus and iterates test records to exclude them (`experiment.py:919`), so the named claim that test data is "not touched" is false even though current mutation requests are clean. The narrower mutation test merely asserts absent constant strings that were never injected (`tests/test_mutation.py:106-123`). A future leakage route through persistence or candidate processing could pass these tests. — Feed evolution a train/validation-only source, make test access fail before `run_held_out`, inject both poison markers into every PLAN §5 location including store rows, and assert absence from failure packets, prompts, requests, responses, and candidate Markdown.

8. [MAJOR] Token totals are accepted independently from their components — `src/skill_lab/agent.py:190` — `_response_values()` trusts a supplied `total_tokens` rather than requiring or deriving `input_tokens + output_tokens`; `_evaluate_slot()` later persists component sums separately from `trajectory.tokens` (`experiment.py:1467-1495`). Any OpenAI-compatible provider returning inconsistent usage silently corrupts total-token comparisons and reports. The committed mock happens to be clean, but neither the model nor tests enforce the accounting invariant. — Derive total tokens from the two components or reject any supplied mismatch, and add per-call, per-run, summary, and artifact sum assertions.

9. [MAJOR] The frozen CLI workflow is incomplete, and `evolve` advertises an artifact path without writing an artifact — `src/skill_lab/cli.py:112` — the command runs evolution into SQLite/candidate directories and then prints `artifact_path`, but never calls `write_artifact`; `skill-lab --help` lists no `held-out` command at all, and `skill-lab held-out --experiment artifacts/example-mock` exits 2 with `No such command 'held-out'`. This prevents the specified separate held-out gate and can leave a paid `evolve` run without the promised report/raw artifact bundle. — Implement the frozen `held-out` command and make baseline/evolve outputs durable artifact bundles (or stop labeling an unwritten path as an artifact), with CLI tests for the full live-gated workflow.
